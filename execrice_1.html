فروش

در زمینه فروش لپ‌تاپ، کنسول بازی و لوازم جانبی فعالیت می‌کنم.

برنامه‌نویسی (فریلنسری)

به‌صورت فریلنسری در حوزه توسعه وب کار می‌کنم و هم بخش سرور (بک‌اند) و هم بخش ظاهری و تعاملی سایت (فرانت‌اند) را انجام می‌دهم؛ از طراحی و نوشتن API گرفته تا ساخت رابط کاربری و اتصال آن به سرور.

توسعه بک‌اند

  • طراحی و نوشتن API با فریم‌ورک Django و زبان Python
  • طراحی ساختار پایگاه داده و مدل‌ها
  • پیاده‌سازی احراز هویت و مدیریت کاربران
  • آماده‌سازی API برای استفاده در فرانت‌اند و اپلیکیشن‌ها

توسعه فرانت‌اند

  • ساخت رابط کاربری با Next.js و React
  • طراحی صفحات واکنش‌گرا (سازگار با موبایل و دسکتاپ)
  • اتصال صفحات به API و نمایش داده‌ها

ابزارها و تکنولوژی‌ها

  • زبان‌ها: Python، JavaScript، HTML، CSS
  • بک‌اند: Django
  • فرانت‌اند: Next.js، React

موسیقی
