# صفحه شخصی امین

یک صفحه وب شخصی که فقط با HTML ساده نوشته شده است (بدون CSS و جاوااسکریپت).

## نحوه اجرا

فایل `index.html` را در هر مرورگری (Chrome، Firefox، Edge و ...) باز کنید. نیازی به نصب یا سرور نیست.

## ساختار فایل‌ها

- `index.html`: خود صفحه وب
- `README.md`: همین توضیحات

## محتوای صفحه

1. **اطلاعات شخصی**
   - نام: امین
   - تاریخ تولد: ۳ اردیبهشت ۱۳۸۴

2. **اطلاعات تحصیلی**
   - رشته: مهندسی کامپیوتر، ترم هفتم
   - برنامه هفتگی ترم جاری (در قالب جدول)

3. **اطلاعات شغلی**
   - فروش لپ‌تاپ، کنسول بازی و لوازم جانبی
   - برنامه‌نویسی فریلنسری
     - بک‌اند: نوشتن API با Django
     - فرانت‌اند: Next.js و React
   - موسیقی: آهنگسازی، عضویت در گروه موسیقی، و آهنگسازی بازی ویدیویی [Eddie's Last Shift](https://store.steampowered.com/app/4892230/Eddies_Last_Shift/)

## تگ‌های HTML استفاده‌شده

| تگ | کاربرد |
| --- | --- |
| `<h1>` تا `<h4>` | عنوان‌ها و زیرعنوان‌ها |
| `<p>` | پاراگراف |
| `<ul>` و `<li>` | فهرست‌ها |
| `<table>`, `<tr>`, `<th>`, `<td>` | جدول برنامه هفتگی |
| `rowspan` | ادغام خانه روز برای روزهایی که بیش از یک درس دارند |
| `<a>` | لینک به بازی در استیم |
| `<b>` و `<small>` | پررنگ‌کردن و کوچک‌کردن متن |
| `<hr>` | خط جداکننده بخش‌ها |
